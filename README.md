# Easy Cast (Android TV receiver)
1. Push this folder to a GitHub repo. Actions builds the APK (Actions tab > Build Easy Cast > Artifacts).
2. Install the APK on the Honton stick, open Easy Cast.
3. On a laptop or phone (same Wi-Fi), open the https address shown on the TV, accept the certificate notice once.
4. Mirror Screen: laptop only. Cast Video: laptop or phone, TV remote controls play, pause and seek.
